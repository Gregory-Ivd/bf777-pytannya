# Питання до бухгалтерки БФ «Мир і Добробут 777»

Анкета для Катерини Дисюк: гроші фонду, реабілітаційний центр, видачі «Є надія».
Відповіді потрібні для сайту www.myridobro.org і грантових заявок.

**Сторінка:** https://gregory-ivd.github.io/bf777-pytannya/ — відкривати лише з посиланням `?k=…`.

## Як зберігаються відповіді

Кожна відповідь іде окремим запитом через 1,2 с після того, як людина перестала друкувати,
і при виході з поля. Приймає їх Google Apps Script (`apps-script/Code.gs`) і пише в таблицю
на Диску власника — один рядок на питання. Паралельно відповідь лишається в `localStorage`
пристрою, тож без інтернету нічого не губиться.

Ключ `ACCESS_KEY` зберігається лише у властивостях скрипта і в посиланні для Катерини.
У репозиторії ключа немає. Без правильного ключа скрипт нічого не записує і не віддає.

Персональних даних отримувачів допомоги анкета не збирає — про це є попередження на сторінці.
Сторінка закрита від пошуковиків (`noindex`, `robots.txt`).
